# Clip Culture

Local-first AI video clipper and editor for Windows. Give it a long video (up to ~1 hour) and it finds the moments worth turning into Reels/TikToks/Shorts, cuts and reframes them to 9:16, adds captions, titles and hashtags, and lets you refine everything in a timeline editor before exporting. **Videos never leave your PC. No accounts. No watermark.**

## Run it

Double-click **`Clip Culture.bat`** (builds on first run), or:

```
npm run dev              # development
npm run build && npm start
npm test                 # regression tests for the render pipeline
```

All files live under this folder: `data\` (database), `projects\` (per-project analysis), `exports\` (finished videos), `temp\`, `ai\` (models), `assets\music\`.
Override the location with the `REELFORGE_HOME` environment variable.

## What it does

| Step | How |
|---|---|
| Import | MP4/MOV/MKV/AVI/WebM by drag & drop, **or paste a video link** (YouTube and most sites, via yt-dlp, saved in `downloads\`; needs internet only for that step); reads duration, resolution, codec, fps, audio |
| Transcribe | faster-whisper `large-v3-turbo` on your NVIDIA GPU (CPU fallback), word-level timestamps |
| Find highlights | Local LLM (Qwen2.5-7B) reads the transcript in windows and picks standalone moments, scored on hook, emotion, information, story, standalone-ness, ending and engagement, plus audio energy. Count and length depend on the content (~1 clip per 8 min, never forced) |
| Trim | Snaps to sentence ends, drops leading fillers, cuts long pauses (>1.1 s) but keeps natural speech |
| Reframe 9:16 | YuNet face detection, active-speaker heuristic (mouth motion + size, with hysteresis), smoothed camera path |
| Captions | Large word-highlighted TikTok-style captions, fully styleable and editable |
| Metadata | Title, hook, social caption, hashtags per clip, all editable, generated from what is actually said |
| Versions | Regenerate a moment (stronger hook / shorter / more context / more emotional / information / AI decides); every version is kept |
| Editor | Timeline (video, captions, text, images, music, zoom): trim, split, delete, duplicate, reorder, undo/redo, zoom keyframes, transitions, effects, images, text with animations, camera drag |
| Music | 10 built-in original tracks (CC0) in categories, or add your own; volume, fades, ducking under speech |
| Export | Reels / TikTok / Shorts / Facebook Reels presets, 1080x1920, H.264/HEVC, NVENC or x264, advanced settings |
| Safety | Autosave, crash recovery, checkpoints, non-destructive (the source video is never modified) |

## Setup notes (already done on this PC)

- Speech/LLM environment: Python 3.12 venv in `ai\venv`
  `py -3.12 -m venv ai\venv` then `pip install faster-whisper nvidia-cublas-cu12 nvidia-cudnn-cu12==9.* nvidia-cuda-runtime-cu12 opencv-python-headless` and `pip install llama-cpp-python==0.3.4 --only-binary=:all: --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cu124`
  (0.3.4 on purpose: newer wheels use AVX512 and crash on CPUs without it, such as the Ryzen 5700G.)
- Models download into `ai\models` on first use (Whisper ~1.5 GB, Qwen2.5-7B ~4.5 GB, YuNet 230 KB).
- Music library is generated by `npm run music` (`tools\make_music.py`).

## Known limitations

- Speaker detection is a mouth-motion heuristic, not true diarization; with two people talking over each other it may pick the wrong one (you can drag the camera in the editor).
- Laughter, speaker change and scene-change signals are not used for scoring yet; audio energy is.
- The built-in music is synthesized and simple; use "Add your own music" for polished tracks.
- Preview approximates crossfades and ducking; the export is the exact result.
- "Smart editing" by natural-language commands is intentionally not built yet (the spec defers it).
